# Sources and limits of the four figures

Each JSON in this directory records the actual visible labels, physical size, source identities and output hashes. All figures use Arial at least 9 points at 507-point report width. PNGs are accompanied by editable text-based SVGs in the archive root. No organizer data or third-party player implementation is added.

1. **Fleet investigation:** source notes [1,6] and the preserved factory reconstruction records. Human direction describes the campaign role; the reproduction was dispatched through the strategist. The diagram does not claim that Jon personally executed every step or that reviewer intervention caused a game-score gain.
2. **Entered deck:** source note [7], recovered deck hash 92b92bac and the previously inspected card-data identity. Poffin searches up to two Basics with 70 HP or less. Normal evolution restrictions apply. Punk Up triggers on evolution from hand and attaches up to five Basic Darkness from the deck to Marnie's Pokemon. Each Froslass places one Checkup counter on each Ability Pokemon on either side except all Froslass. A Munkidori with Darkness attached can move up to three counters from one friendly Pokemon to one opposing Pokemon once during the turn. Those counters need not originate from Froslass. Transfer precedes an attack; Shadow Bullet prints 180 Active and 30 to one Benched target before modifiers. The illustration shows resource relationships across turns, not a complete executable sequence.
3. **Development grid:** [saved calculation](../numerical/verified-results.json) and [methods](../numerical/METHODS.md). Card, rule and combined values use three, two and three within-batch contrasts, respectively, with shared factorial arms. The +1.71 interaction and interval come exclusively from the single four-arm batch. Subtracting differently pooled grid estimates does not reproduce that interaction. Zero denotes a difference reference, not zero baseline win rate. Shading provides ordinal emphasis, not a calibrated heatmap scale.
4. **Seven-opponent chart:** identical original cell means, sample-score variances and conditional intervals in the saved calculation. Win=1, draw=0.5, loss=0.
